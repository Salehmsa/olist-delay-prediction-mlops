# Runtime dependencies — pinned for reproducible inference.

# IMPORTANT: scikit-learn is pinned to 1.8.0 because that is the EXACT
# version your models/*.pkl (imputer, encoder, scaler) were fitted under -
# confirmed by sklearn's own InconsistentVersionWarning at load time, not
# guessed (it names the fitting version directly:
# "Trying to unpickle estimator SimpleImputer from version 1.8.0 when
# using version 1.5.2"). 1.5.2 was the earlier pin here and it was wrong -
# it happened to load and transform without crashing when checked, but
# sklearn's own docs make no correctness guarantee across versions
# ("might lead to breaking code or invalid results"), and a silently wrong
# prediction is worse than a crash because it looks fine. Matching the
# fitting version exactly removes that risk instead of hoping it's fine.
# If you ever re-fit against a different scikit-learn version, update this
# pin to match — same for pandas/numpy: confirm with
# pip freeze | findstr /I "pandas numpy scikit-learn joblib"
# run inside the same environment/kernel you used for Notebooks 05-06.
